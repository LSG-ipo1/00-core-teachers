# Portfoli — README professional del projecte (context, funcionalitats, stack)

## 🎯 Objectius d’aprenentatge

- Entendre la funció d’un README en un projecte professional.
- Explicar clarament què fa un projecte i quin problema resol.
- Documentar les funcionalitats principals del projecte.
- Identificar i comunicar el stack tecnològic utilitzat.

---

## 💡 Resultats d’aprenentatge

📌 **RA1.** _Distingeix les característiques del sector productiu i defineix els llocs de treball, relacionant-los amb les competències professionals expressades en el títol._

> 🧭 Es treballa quan l’alumnat presenta el projecte de manera comprensible per a una empresa o equip tècnic.

📌 **RA4.** _Analitza i avalua el seu potencial professional i els seus interessos per a guiar-se en el procés d'autoorientació._

> 💡 S’activa en identificar què ha fet realment dins del projecte i quines competències demostra.

📌 **RA5.** _Aplica estratègies per a l’aprenentatge autònom i la comunicació professional._

> 💬 Es posa en pràctica en la redacció clara i estructurada de la documentació tècnica.

---

## ⏱️ Minut a minut (45’)

- **0–5’ | Obertura**

  Context de la sessió.

  > “Un projecte sense README és com un projecte que ningú entén.”

---

- **5–10’ | Explicació molt breu**

  Parts bàsiques d’un README professional:

  1. **Context del projecte**
  2. **Funcionalitats principals**
  3. **Stack tecnològic**

  Errors habituals:

  - README buit o molt curt
  - descriure només el codi i no el problema
  - no explicar què ha fet l’alumne

---

- **10–25’ | Redacció del context del projecte**

  Cada alumne escriu:

  - què fa el projecte
  - quin problema resol
  - en quin context es va crear (assignatura, projecte personal, etc.)

  Condicions:

  - màx. 5–6 línies
  - llenguatge clar
  - entenedor per a algú que no coneix el projecte

---

- **25–35’ | Redacció de funcionalitats**

  L’alumnat descriu **3–6 funcionalitats principals**.

  Exemple d’estructura:

  - registre d’usuaris
  - cerca d’elements
  - filtratge per categories
  - visualització de dades

  Criteri:

  > explicar què pot fer l’usuari amb el projecte.

---

- **35–45’ | Stack tecnològic**

  Cada alumne documenta les tecnologies utilitzades.

  Exemple:

  - HTML / CSS
  - JavaScript
  - Next.js
  - Node.js
  - MongoDB

  El docent revisa ràpidament que:

  - el stack sigui correcte
  - coincideixi amb el projecte real.

---

## 📦 Materials de suport

- 💻 Ordinador amb accés a GitHub.
- 🔗 Repositoris del projecte seleccionat.
- 📝 Editor Markdown (GitHub / VSCode).

---

## 🧩 Resultat de la sessió

- README del projecte amb:

  - context del projecte
  - funcionalitats principals
  - stack tecnològic

- Primera documentació professional del projecte.
