# Portfoli — README avançat (captures, demo, estructura, decisions tècniques)

## 🎯 Objectius d’aprenentatge

- Millorar la documentació del projecte perquè sigui clara per a una empresa o desenvolupador.
- Aprendre a utilitzar captures de pantalla per explicar el funcionament d’un projecte.
- Mostrar com s’organitza el codi dins del projecte.
- Explicar decisions tècniques rellevants preses durant el desenvolupament.

---

## 💡 Resultats d’aprenentatge

📌 **RA1.** _Distingeix les característiques del sector productiu i defineix els llocs de treball, relacionant-los amb les competències professionals expressades en el títol._

> 🧭 Es treballa quan l’alumnat presenta el projecte de manera comprensible per a un equip tècnic.

📌 **RA4.** _Analitza i avalua el seu potencial professional i els seus interessos per a guiar-se en el procés d'autoorientació._

> 💡 S’activa en explicar quines decisions tècniques ha pres i per què.

📌 **RA5.** _Aplica estratègies per a l’aprenentatge autònom i la comunicació professional._

> 💬 Es posa en pràctica en la redacció d’una documentació tècnica clara i estructurada.

---

## ⏱️ Minut a minut (45’)

- **0–5’ | Obertura**

  Context de la sessió.

  > “Un bon README permet entendre el projecte sense haver de mirar el codi.”

---

- **5–10’ | Explicació molt breu**

  Elements avançats d’un README professional:

  - captures de pantalla
  - demo o enllaç al projecte
  - estructura del projecte
  - decisions tècniques

  Errors habituals:

  - README només amb text
  - captures sense context
  - explicar massa el codi i poc el projecte

---

- **10–20’ | Captures de pantalla**

  Cada alumne crea **2–3 captures** del projecte:

  - pantalla principal
  - funcionalitat important
  - resultat visual del projecte

  Després les afegeix al README amb una petita descripció.

---

- **20–30’ | Enllaç de demo**

  Si el projecte és desplegable:

  - afegir enllaç a la demo (GitHub Pages, Vercel, etc.)

  Si no ho és:

  - explicar breument com executar-lo.

---

- **30–40’ | Estructura del projecte**

  L’alumnat explica breument l’organització del projecte.

  Objectiu:

  - ajudar a entendre com està organitzat el codi.

---

- **40–45’ | Decisions tècniques**

Cada alumne escriu **2–3 decisions tècniques**.

Exemple:

- per què s’ha utilitzat una llibreria
- per què s’ha escollit una arquitectura
- com s’ha resolt un problema tècnic

---

## 📦 Materials de suport

- 💻 Ordinador amb accés a GitHub.
- 🔗 Repositori del projecte.
- 🖼️ Eina per fer captures de pantalla.

---

## 🧩 Resultat de la sessió

- README ampliat amb:

- captures de pantalla
- enllaç de demo o instruccions d’execució
- estructura del projecte
- decisions tècniques

- Documentació del projecte preparada per al portfoli.
